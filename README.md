```txt
《千年土地翻了身》是董希文1963年油画，藏中国美术馆。

这幅画代表新中国美术发展。董希文三进西藏写生，积累素材。他以朴素画风表现西藏农奴翻身做主，在土地上耕耘的喜悦。
画面充满动感。人物后仰，牦牛奋蹄，笔触方向一致。雪山蓝天带来不一样的春天。
对角线构图和桃红上衣与左下阴影对比。这表现出高原阳光，也表现出人物内心的激动喜悦。
```
